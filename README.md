# Посмотри в окно

Проектная работа третьего спринта курса «Фронтенд-разработчик» Яндекс Практикума.

CSS для приложения поиска видео по городу и времени суток. Вёрстка выполнена с Flexbox, локальными шрифтами, кастомными чекбоксами и состояниями интерактивных элементов.

Для просмотра откройте index.html в браузере. Для загрузки видео требуется доступ к интернету.

Репозиторий проекта — https://github.com/Innpot/posmotri-v-okno-ad
